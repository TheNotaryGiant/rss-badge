# Valid RSS Badge - The Notary Giant

Official W3C Valid RSS badge for https://thenotarygiant.com

This repo hosts the Valid RSS badge that validates the RSS feed via the W3C Feed Validation Service.

**Live Validator:** http://validator.w3.org/feed/check.cgi?url=https%3A//thenotarygiant.com/feed.xml

**RSS Feed:** https://thenotarygiant.com/feed.xml

## What is this badge?

The Valid RSS badge indicates that the RSS feed at thenotarygiant.com/feed.xml is compliant with RSS standards and will work correctly in news readers, Feedly, Apple News, and other aggregators. Clicking the badge runs a live validation check at W3C.
